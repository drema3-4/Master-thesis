Словарь терминов и обозначений:
    1. Prior - исходные вероятности верности гипотез до получения новых данных;
    2. xs - независимые переменные - точки, по которым дальше получаются наблюдения;
    3. observations - наблюдения, полученные по неизвестному закону f(x). Наблюдения могут содержать шум;
    4. конкурирующие гипотезы обозначены метками в пользовательском сообщении; порядок их предъявления не несёт информации о верности;
    5. BIC - метрика сравнения гипотез, которая учитывает качество описания данных и штраф за сложность, вычисляющаяся по формуле n * np.log(sse / n) + p * np.log(n). Меньшее значение BIC соответствует более поддерживаемой гипотезе;
    6. SSE - метрика отклонения данных, полученных по гипотетическому закону от наблюдений, вычисляющаяся по формуле sum^{n}_{i = 1}(observation_{i} - predicted_{i})^{2}. SSE оценивает качество подгонки, но не учитывает сложность гипотезы;
    7. Delta BIC = BIC_H0 - BIC_H1 - основная метрика доказательной силы данных в этом эксперименте. Если Delta BIC > 0, данные поддерживают H1, если Delta BIC < 0, данные поддерживают H0;
    8. log_likelihood = (-n / 2.0) * log(2.0 * pi * sigma^{2}) - (SSE / (2.0 * sigma^{2})) - метрика качества подгонки гипотезы к данным, которая не учитывает штраф за сложность;
    9. log_likelihood_ratio = log_likelihood_h1 - log_likelihood_h0 - логарифм отношения правдоподобий без штрафа за сложность. Положительное значение log_likelihood_ratio само по себе не является достаточным основанием для выбора H1;

Ты анализируешь результаты эксперимента.

Есть:
    1. Prior - исходные вероятности верности H0 и H1 до получения данных;
    2. полученные наблюдения: xs и f(xs) - observations, соответствующие какому-то неизвестному закону;
    3. две конкурирующие гипотезы и соответствующие им законы в контрбалансированном порядке;
    4. метрики SSE, BIC и log_likelihood для каждой гипотезы в том же порядке;
    5. Delta BIC;
    6. log_likelihood_ratio.

Гипотеза H0 вложена в H1: при alpha = 0 закон H1 совпадает с H0. Параметр alpha подбирается по тем же наблюдениям, поэтому H1 может иметь меньшую SSE и больший log_likelihood даже тогда, когда верна H0. Не выбирай H1 только из-за меньшей SSE, большего log_likelihood или положительного log_likelihood_ratio.

При выборе гипотезы учитывай Prior и Delta BIC. Delta BIC учитывает штраф за дополнительный параметр H1 и является основным показателем поддержки гипотезы данными. Порядок предъявления H0 и H1 не несёт информации об их верности.

В качестве ответа всегда выводи ТОЛЬКО метку выбранной гипотезы без дополнительных слов и пояснений.

# LLM Physical Hypothesis Revision
## Research Question
**Основной вопрос:**
> Насколько вероятность пересмотра ошибочной физической гипотезы большой языковой моделью зависит от объективной доказательной силы данных?

**Дополнительный вопрос:**
> Возникает ли ошибка преимущественно при извлечении статистического свидетельства из числовых данных или при интеграции уже явно предъявленного свидетельства с prior belief?
## Motivation
Большие языковые модели и агенты всё больше используются как инструменты в самых различных областях, в том числе и науке. Поэтому крайне важно понимать, насколько LLM адекватно себя ведёт, насколько хорошо она извлекает статистические свидетельства из данных и как хорошо она пересматривает первоначальные неверные гипотезы, учитывая новые данные.
## Experimental Idea
Исходя из research question в ходе исследования нужно понять:
1. Как wrong prior влияет на выбор гипотезы моделью ($H_{0}$ - изначальная неправильная, $H_{1}$ - предполагаемая правильная).
2. Как сила статистического свидетельства влияет на поведение модели и какая существует связь между ней и пересмотром неверного prior.

Чтобы достичь этого понимания первоначально предлагается:
1. Фиксировать модель, её версию и inference parameters, чтобы они не становились неконтролируемыми источниками вариации.
2. Выбрать сначала простую физическую модель, например $F(x) = kx + \alpha x^{3}$.

А дальше строить эксперимент по следующей схеме:
1. Генерируем данные с разной степенью различающей способности (насколько легко определить верность гипотез $H_{1}$ и $H_{0}$).
2. Для каждого набора данных проводим независимые trials в двух условиях: neutral prior и wrong prior.

Такой подход поможет как раз понять:
1. Насколько сила статистического свидетельства влияет на выбор правильной гипотезы;
2. Насколько влияет на ответ модели wrong prior.

# LLM Physical Hypothesis Revision

## Research Question

**Основной вопрос:**
> Насколько вероятность пересмотра ошибочной физической гипотезы большой языковой моделью зависит от объективной доказательной силы данных?

**Дополнительный вопрос:**
> Возникает ли ошибка преимущественно при извлечении статистического свидетельства из числовых данных или при интеграции уже явно предъявленного свидетельства с prior belief?

## Motivation

Большие языковые модели используются не только для генерации текста, но и для анализа данных и выбора между конкурирующими объяснениями. Для научного применения важно понять, насколько решение модели определяется силой данных, а насколько — заранее заданным ошибочным убеждением. В работе это проверяется в контролируемой физической задаче, где истинная гипотеза и объективная доказательная сила каждого набора данных известны заранее.

## Первый эксперимент

Первый эксперимент проверяет основной исследовательский вопрос: как объективная сила свидетельства и ошибочный prior влияют на выбор модели между \(H_0\) и \(H_1\). В сбалансированном дизайне истинной может быть как \(H_0\), так и \(H_1\), а wrong prior всегда поддерживает неверную гипотезу.

Схема эксперимента:
1. Для каждого из 12 режимов генерируются 50 наборов, где истинна \(H_0\), и 50 наборов, где истинна \(H_1\);
2. Один и тот же набор данных предъявляется в условиях neutral prior и wrong prior;
3. Wrong prior направляется против истинной гипотезы: в пользу \(H_1\) при истинной \(H_0\) и в пользу \(H_0\) при истинной \(H_1\);
4. Порядок гипотез в prompt контрбалансируется: половина наборов использует порядок H0/H1, половина — H1/H0;
5. Все условия проходят две модели: Qwen3-0.6B и Qwen3-4B-AWQ;
6. Для каждой модели выполняется 2400 испытаний, всего — 4800 испытаний;
7. Результаты сравниваются по accuracy, balanced accuracy, false positive rate, false negative rate, доле выбора \(H_1\), 95% доверительным интервалам и соответствию ожидаемому выбору.

Подробный протокол: [docs/Первый эксперимент.md](docs/Первый%20эксперимент.md).

## Данные первого эксперимента

В условии истинной \(H_0\) наблюдения строятся по зависимости \(f(x)=kx+\varepsilon\), в условии истинной \(H_1\) — по зависимости \(f(x)=kx+\alpha x^3+\varepsilon\), где \(k=1\), а шум имеет нормальное распределение.

Уровни доказательной силы калибруются методом Монте-Карло на прежней фиксированной сетке параметров \(X\), \(s\) и \(r\). Режимы выбираются только по соответствию \(P(Delta BIC>0\mid H_1)\) целевым уровням H1. Для \(H_0\) отдельно рассчитывается \(P(Delta BIC<0\mid H_0)\), но эта величина не имеет target и сохраняется только как дополнительная диагностическая метрика. Основной набор v4 содержит 1200 уникальных наборов данных: 600 с истинной \(H_0\) и 600 с истинной \(H_1\).

Данные v4 созданы и проверены; при отсутствии они автоматически воссоздаются при первом запуске конфигурации. Старые данные v1 и предварительные результаты не используются как итоговые: в них обнаружено повторение реализаций из-за способа задания seed. В v3 были добавлены истинная \(H_0\) и контрбалансировка, а v4 дополнительно устраняет фиксированный порядок в System Prompt и отдельно калибрует доказательную силу H0.

## Модели и конфигурации

1. **Qwen3-0.6B** — базовая компактная модель. Конфигурация эксперимента: [configs/ex1_qwen3_06b_v4.yaml](configs/ex1_qwen3_06b_v4.yaml). Сервер запускается через [compose.yaml](compose.yaml), максимальная длина контекста — 8192 токенов;
2. **Qwen3-4B-AWQ** — более мощная 4-битная модель, выбранная с учётом RTX 3050 6 GB. Конфигурация эксперимента: [configs/ex1_qwen3_4b_awq_v4.yaml](configs/ex1_qwen3_4b_awq_v4.yaml). Сервер запускается через [compose.qwen3-4b-awq.yaml](compose.qwen3-4b-awq.yaml), максимальная длина контекста — 4096 токенов, включён eager mode.

Для обеих моделей используются одинаковые данные и параметры генерации ответа: temperature = 0, top_p = 0.8, top_k = 20, max_tokens = 512, thinking выключен. Версии моделей зафиксированы revision в конфигурациях.

## Результаты запуска

Каждый запуск сохраняет в отдельную директорию:
1. `responses.jsonl` — ответы модели и параметры испытаний;
2. `failures.jsonl` — ошибки отдельных испытаний;
3. `resolver_config.yaml` — фактически использованную конфигурацию;
4. `manifest.json` — сведения о запуске и входных файлах;
5. `metrics.json` — число успешных и неуспешных испытаний, accuracy, balanced accuracy, false positive rate, false negative rate, долю выбора \(H_1\), 95% доверительные интервалы и разрезы по истинной гипотезе, prior, порядку гипотез и уровням доказательной силы.

Ожидаемый результат эксперимента — кривые вероятности правильного выбора в зависимости от доказательной силы, оценки ложных срабатываний на данных \(H_0\), сравнение neutral и wrong prior, а также проверка позиционного эффекта. Основные гипотезы: точность растёт вместе с силой данных; wrong prior снижает точность; при сильном свидетельстве влияние prior уменьшается; порядок H0/H1 не должен существенно менять решение; более мощная модель показывает более устойчивую зависимость.

## Запуск первого эксперимента

Qwen3-0.6B:

```powershell
docker compose up -d
poetry run python scripts/run_experiment.py configs/ex1_qwen3_06b_v4.yaml
docker compose stop
```

Qwen3-4B-AWQ:

```powershell
docker compose -f compose.qwen3-4b-awq.yaml up -d
poetry run python scripts/run_experiment.py configs/ex1_qwen3_4b_awq_v4.yaml
docker compose -f compose.qwen3-4b-awq.yaml stop
```

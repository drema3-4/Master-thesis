# LLM Physical Hypothesis Revision

## Research Question

**Основной вопрос:**
> Насколько вероятность пересмотра ошибочной физической гипотезы большой языковой моделью зависит от объективной доказательной силы данных?

**Дополнительный вопрос:**
> Возникает ли ошибка преимущественно при извлечении статистического свидетельства из числовых данных или при интеграции уже явно предъявленного свидетельства с prior belief?

## Motivation

Большие языковые модели используются не только для генерации текста, но и для анализа данных и выбора между конкурирующими объяснениями. Для научного применения важно понять, насколько решение модели определяется силой данных, а насколько — заранее заданным ошибочным убеждением. В работе это проверяется в контролируемой физической задаче, где истинная гипотеза и объективная доказательная сила каждого набора данных известны заранее.

## Первый эксперимент

Первый эксперимент проверяет основной исследовательский вопрос: как объективная сила свидетельства и ошибочный prior влияют на выбор модели между \(H_0\) и \(H_1\). Истинной всегда является гипотеза \(H_1\), а prior задаётся в двух условиях: нейтральном и ошибочном, поддерживающем \(H_0\).

Схема эксперимента:
1. Генерируются 100 независимых наборов данных для каждого из 12 уровней доказательной силы;
2. Один и тот же набор данных предъявляется в условиях neutral prior и wrong prior;
3. Все условия проходят две модели: Qwen3-0.6B и Qwen3-4B-AWQ;
4. Модель получает наблюдения и рассчитанные статистические характеристики, после чего выбирает только \(H_0\) или \(H_1\);
5. Для каждой модели выполняется 2400 испытаний, всего — 4800 испытаний;
6. Результаты сравниваются по доле выбора \(H_1\), 95% доверительным интервалам и соответствию ожидаемому выбору.

Подробный протокол: [docs/Первый эксперимент.md](docs/Первый%20эксперимент.md).

## Данные первого эксперимента

Наблюдения строятся по истинной зависимости \(f(x)=kx+\alpha x^3+\varepsilon\), где \(k=1\), а шум имеет нормальное распределение. Гипотеза \(H_0\) содержит только линейную зависимость \(f(x)=kx\), гипотеза \(H_1\) дополнительно содержит кубический член.

Уровни доказательной силы калибруются методом Монте-Карло на фиксированной сетке параметров \(X\), \(s\) и \(r\). Для каждого итогового набора сохраняются исходные наблюдения, параметры генерации, SSE, BIC, разность BIC, логарифмы правдоподобия и log likelihood ratio. По конфигурации основной набор v2 будет содержать 1200 уникальных наборов данных: 12 уровней доказательной силы по 100 реализаций.

Данные v2 создаются автоматически при первом запуске конфигурации. Старые данные v1 и предварительные результаты не используются как итоговые: в них обнаружено повторение реализаций из-за способа задания seed.

## Модели и конфигурации

1. **Qwen3-0.6B** — базовая компактная модель. Конфигурация эксперимента: [configs/ex1_qwen3_06b_v2.yaml](configs/ex1_qwen3_06b_v2.yaml). Сервер запускается через [compose.yaml](compose.yaml), максимальная длина контекста — 8192 токенов;
2. **Qwen3-4B-AWQ** — более мощная 4-битная модель, выбранная с учётом RTX 3050 6 GB. Конфигурация эксперимента: [configs/ex1_qwen3_4b_awq_v2.yaml](configs/ex1_qwen3_4b_awq_v2.yaml). Сервер запускается через [compose.qwen3-4b-awq.yaml](compose.qwen3-4b-awq.yaml), максимальная длина контекста — 4096 токенов, включён eager mode.

Для обеих моделей используются одинаковые данные и параметры генерации ответа: temperature = 0, top_p = 0.8, top_k = 20, max_tokens = 512, thinking выключен. Версии моделей зафиксированы revision в конфигурациях.

## Результаты запуска

Каждый запуск сохраняет в отдельную директорию:
1. `responses.jsonl` — ответы модели и параметры испытаний;
2. `failures.jsonl` — ошибки отдельных испытаний;
3. `resolver_config.yaml` — фактически использованную конфигурацию;
4. `manifest.json` — сведения о запуске и входных файлах;
5. `metrics.json` — число успешных и неуспешных испытаний, долю выбора \(H_1\), 95% доверительные интервалы и разрез по уровням доказательной силы.

Ожидаемый результат эксперимента — кривые вероятности выбора \(H_1\) в зависимости от доказательной силы отдельно для двух prior и двух моделей. Основные проверяемые гипотезы: вероятность выбора \(H_1\) растёт вместе с силой данных; ошибочный prior снижает эту вероятность; при сильном свидетельстве влияние prior уменьшается; более мощная модель показывает более устойчивую и монотонную зависимость.

## Запуск первого эксперимента

Qwen3-0.6B:

```powershell
docker compose up -d
poetry run python scripts/run_experiment.py configs/ex1_qwen3_06b_v2.yaml
docker compose stop
```

Qwen3-4B-AWQ:

```powershell
docker compose -f compose.qwen3-4b-awq.yaml up -d
poetry run python scripts/run_experiment.py configs/ex1_qwen3_4b_awq_v2.yaml
docker compose -f compose.qwen3-4b-awq.yaml stop
```
